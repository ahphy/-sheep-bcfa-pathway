## 图注与假说边界

图示为待验证的瘤胃细菌来源假说。乙酰-CoA或丙酰-CoA作为起始引物，酰基转移酶（AT）选择丙二酰-CoA、甲基丙二酰-CoA或乙基丙二酰-CoA；KS催化缩合，ACP承载中间体。图中每次延长后的饱和骨架需要兼容的KR、DH、ER还原功能或其他等效酶系，不能由“存在PKS基因”直接推出。模块化PKS的供体选择与模块顺序可为内部支链构建提供机制基础，但尚未鉴定与这三种目标酸对应的瘤胃细菌模块组合。

CCR（巴豆酰-CoA羧化还原酶）可利用巴豆酰-CoA、CO2及NADPH形成乙基丙二酰-CoA；这是已知细菌酶学能力，不证明相关瘤胃菌具有同等活性。甲基丙二酰-CoA来源可涉及丙酰-CoA羧化等途径，具体菌株及区室条件未确定。

共享主线三个延长轮次依次保留2、3/4、2个供体碳，末次羧基端二碳延长使支链C2→C4。R表示引物烃基，X表示支链；仅列MOA（R=CH3/X=CH3）、MNA（R=CH2CH3/X=CH3）、EOA（R=CH3/X=CH2CH3）三个配对。RDKit验证最终连接、分子式及C4支链；这些检查只证明碳骨架模型合理，不验证生物途径。

特定链长终止和游离酸释放可能涉及硫酯酶或其他终止机制，图中水解未指定酶身份。可能的宿主暴露路径包括游离酸跨瘤胃上皮吸收，以及微生物脂质经下游消化道释放、吸收后被宿主利用；两条路径及脂肪积累贡献均未被本图证实。下方箭头表示可能路径，不代表所有目标酸均具有相同吸收或沉积效率。

上方CCR供体生成表示一般酶学基础；共享主线虚线及底部转运描述表示假说。PKS相关基因或转录信号不能单独确定产物、链长、完整还原能力及合成通量。需要菌株/基因簇定位、模块功能验证、目标酸鉴定及同位素示踪。立体构型未指定。本次依据用户提供的机制论述绘图，没有新增文献检索或独立核验其引文。
